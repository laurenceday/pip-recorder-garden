**Entry.** The receipted run branch `fiat/deeper-interactive-recorder-learning-for-a-five` at `a26387445196aa0ea7fdcd0590c1b895bba3762d`, where `npm ci && npm run check && npm run build` passes 43 of 43 tests and the production JavaScript is 219.21 kB.
